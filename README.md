# FRIDAY v1.1 🤖

FRIDAY is a modular Android AI assistant project.

## Current version

v1.1 — Android chat foundation

## Planned modules

- AI conversational brain
- Voice input/output
- Vision
- Approved memory
- Web tools
- Android commands
- Owner Mode
- Secure backend

## Security

The OpenAI API secret must never be stored inside the Android APK.

The intended architecture is:

Phone → Secure Backend → AI API

## Build

The Android project is intended to be built using a cloud CI/CD service.
